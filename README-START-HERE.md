# Start here — IBM Fusion Lab 01 installer

The step-by-step Lab 1 installation guide is now on its own page:

**[Lab 1 — Installation and Configuration](docs/LAB01-INSTALLATION-AND-CONFIGURATION.md)**

The guide covers downloading the packaged Ansible installer, SecureCRT SFTP transfer, kubeconfig setup, obtaining TechZone lab values, the read-only `plan`, the actual `deploy`, Storage Scale GUI prompts, installation monitoring, and recovery from failed Scale authentication.

If you do not have an Ansible control node yet, start with [Getting Started from Zero](docs/GETTING-STARTED-FROM-ZERO.md), including the [Hyper-V + Ubuntu prerequisites](docs/HYPERV-UBUNTU-PREREQUISITES.md).

> **Lab environments only.** The deployment can erase explicitly selected Ceph disks and reboot OpenShift worker nodes. Do not run it against production clusters.
